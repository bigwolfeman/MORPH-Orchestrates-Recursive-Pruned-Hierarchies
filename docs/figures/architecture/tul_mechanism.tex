% LXTUL, the latent-selected slot loop: THE SIMPLE DRAWING (README figure).
% Redrawn 2026-10-07 on Wolfe's feedback ("way too much going on ... just show LXTUL").
% It shows the slot loop alone. The pointer head, the DITTO phase, the train-only teacher and
% span decoder, the strict-geometry table, the equations and the measured results are NOT
% drawn here. The full drawing, with every one of those and its code citations, is
% tul_mechanism_detailed.tex; the measured results are tul_results.tex.
%
% Every drawn fact, with its code citation (file:line at commit 5e913cad, as re-read for the
% detailed drawing; recipe = composed Hydra config `lxtul_pointer_ditto`, built on
% morph/configs/lxtul.yaml):
%  1. THE ROW. Spans end at a boundary: `.;!?` + substrings "\n", em dash, en dash, "--";
%     min span 4, cap 32 (tul_layout.py:152-169, BoundaryRule). After every span the packer
%     puts prefix_k = 4 slot positions (tul_layout.py:335-337); cell i of slot s sits at
%     slot_index[s] + i (transformer.py:5953). fan_k 4 aliases slot_cells 4
%     (tul_setup.py:292-299).
%  2. PRELUDE: every position once (4 blocks). Under strict geometry a position reads its own
%     span only (tul_layout.py:1028).
%  3. TOKENS SKIP THE LOOP: only slot positions enter `_tul_core` (transformer.py:5829); the
%     token positions keep their prelude state into the coda.
%  4. THE LOOP (`_tul_core`, transformer.py:5829): each pass runs the 6 shared core blocks over
%     the 4 cells of every slot; per-slot depth T ~ Poisson(6) clamped to [1, 8]
%     (transformer.py:5673-5674). After every pass `_lsel_pass` (called 7372, def 9816):
%     FanRouter (tul_fan_route.py:368) scores the 4 cells; the forward FOLLOWS the router
%     (`fan_lsel_train_follow: router`, transformer.py:9807-9810, 9845-9846); every slot whose
%     depth continues has all 4 cells reset to the winner (reset_to_winner,
%     tul_fan_route.py:510, called transformer.py:9857 with `dslot > t + 1`, so the last
%     pass never resets and its router pick is the final winner w).
%  5. WRITE: `fan_lsel_read: winner` (tul.py:679): `_fan_route_cells` (transformer.py:9752,
%     used at 14051-14052) zeroes every loser; prefix_project (tul.py:6843, called
%     transformer.py:14095) writes the winner through W_prefix[w] into slot position w. The 3
%     loser positions are exactly 0.
%  6. CODA (4 blocks): a token reads its own span + the prefix positions of every earlier slot
%     (tul_layout.py:1034); a slot position reads itself only (tul_layout.py:1041). The next
%     span's tokens are decoded with every earlier slot's winner in view.
%  7. "Between spans, the loop is the only path": `tul.tg_geometry: strict` (prelude same span,
%     coda as in 6, conv / value shift reset per segment and coda injections at slot positions
%     zeroed, tul.py:952-957; retention off). The loop itself lets a cell read every cell of
%     every earlier slot (`slot_cell_relation`, transformer.py:1609).
%
% Palette: Paul Tol (as morph_overview.tex). Wolfe is red-green colour blind: the winner is
% marked by a dark fill, a heavy black border and a star, never by hue; no meaning rides on
% hue alone.
% Compile: pdflatex tul_mechanism.tex
%          pdftoppm -png -r 220 -singlefile tul_mechanism.pdf ../tul_mechanism

% One pass: #1 = name, #2 = x of the core box, #3 = winner row (1..4, 0 = none), #4 = label.
% Cells sit at y = +0.84, +0.28, -0.28, -0.84.
\newcommand{\onepass}[4]{%
  \node[core] (#1box) at (#2, 0) {shared\\core};
  \node[font=\sffamily\bfseries, text=loopC, above=3pt of #1box] {#4};
  \foreach \r/\yy in {1/0.84, 2/0.28, 3/-0.28, 4/-0.84} {
    \ifnum\r=#3
      \node[win] (#1c\r) at ($(#1box.east)+(0.75,\yy)$) {};
    \else
      \node[cell] (#1c\r) at ($(#1box.east)+(0.75,\yy)$) {};
    \fi
    \draw[As, draw=loopC] (#1box.east |- #1c\r) -- (#1c\r.west);
  }
}
