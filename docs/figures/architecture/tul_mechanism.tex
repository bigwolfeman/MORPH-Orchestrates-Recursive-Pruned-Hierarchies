% locked 2026-10-04). Decision record:
% .agents/notes/implemented/architecture/2026-10-04-lxtul-primary-candidate.md.
% Redrawn 2026-10-05. Every fact below was read in the code at commit ef64e10e (file:line
% are at that commit; the working tree was being edited by another agent at the time) and
% in the composed Hydra config `lxtul` (compose run on CPU, 2026-10-05).
%
% What it draws, top to bottom:
%  1. THE ROW. 1024 tokens; after every span the packer puts prefix_k = 4 slot positions;
%     L_total = seq_len + prefix_k * max_slots = 1024 + 4*64 = 1280
%     (tul_layout.py:335-337). Boundary = `.;!?` + substrings "\n", em dash, en dash, "--"
%     (composed tul.boundary_chars / boundary_substrings), min span 4, cap 32
%     (tul_layout.py:152-169, BoundaryRule). Every slot position gets the same input
%     E_slot + W_sent embed(t_last) (`slot_seed: boundary`, tul.py:6301-6313).
%  2. STRICT GEOMETRY (`tul.tg_geometry: strict`, `tg_coda_prefix_reach: all`,
%     `tg_coda_token_reach` 0): prelude = same span only, a slot position also sees its own
%     earlier positions (tul_layout.py:984); coda token = own span + every earlier slot's
%     prefix positions (tul_layout.py:987); coda prefix position = itself only
%     (tul_layout.py:997); conv / value shift / retention reset per segment and the coda's
%     per-layer injections at slot positions are zeroed (tul.py:826-831). Loop: a cell reads
%     every cell of its own slot and every cell of every earlier slot
%     (`slot_cell_relation`, transformer.py:1606; loop_reach 0, fan_lineage off).
%  3. SEED (TULSlotRegister, tul.py:5746; forward sum at tul.py:5847; added to the gathered
%     prelude state at transformer.py:5848). Cell i of slot s sits at row position
%     slot_index[s] + i (transformer.py:5798), so e_i = normed prelude state at that position
%     + W_o Attn(Q_i; span s's prelude token states) + P_cell[i]. W_o, P_cell zero-init.
%     h_0 = core_init(e) (transformer.py:5975). Carrier = Hyper-Connection, 4 streams x d 1024.
%  4. THE LOOP (`_tul_core`): 6 shared core blocks per pass; per-slot depth
%     T ~ Poisson(6) clamped to [1, 8] (transformer.py:5499; model.mean_depth 6,
%     max_depth 8), bptt_depth 8 = full BPTT. Every pass re-injects the cell's own e_i on the
%     ctx channels, h_ctx <- A h_ctx + dt e_ctx, A init 0.447 (DiagonalInjection,
%     transformer.py:718). After every pass: RMSNorm with one gain g shared by all passes
%     (transformer.py:7028, `slot_cell_pass_norm: rms`), then `_lsel_pass`
%     (transformer.py:7191 -> 9626): FanRouter (tul_fan_route.py:368) scores the 4 cells
%     (detached) against the slot's ctx; the loop FOLLOWS the router (`fan_lsel_train_follow:
%     router`); every slot whose depth continues has all 4 cells reset to the winner
%     (reset_to_winner, tul_fan_route.py:510). The last pass never resets: the 4 final
%     candidates stay, later slots' loops read all 4, the coda reads the winner alone.
%     Loop losses: epivol diversity on passes 1-2 (fan_repel_lambda 0.1), fixed-point term
%     on the last pass (core_fixed_point_lambda 0.1, transformer.py:6143), gain hinge
%     (slot_gain_lambda 100 at target 0.9, base.yaml).
%  5. ROUTER TEACHER (train only, dashed). EMA twin of the prelude (FanTargetFront,
%     tul_fan_route.py:91; momentum fan_target_ema 0.996, tul.py:494); z_s = LayerNorm of the
%     twin's states mean-pooled over span s+1 (transformer.py:9421-9452). g = FanLatentHead
%     (tul_fan_route.py:461) reads DETACHED cells (`fan_lsel_head_input: detached`,
%     transformer.py:9705); teacher pick = argmin_i ||g(c_i) - z||^2; router CE onto it at
%     every pass (transformer.py:9626-9660); exit loss (`_lsel_finish`,
%     transformer.py:9676) = 1.0 * relaxed WTA on g + 0.2 * L_enc floor on the ONLINE
%     prelude's pooled states + 1.0 * router CE.
%  6. WRITE. `fan_lsel_read: winner`: `_fan_route_cells` (transformer.py:9562) zeroes every
%     loser, prefix_project (tul.py:6354) sends cell k through W_prefix[k] into prefix
%     position k (transformer.py:13627-13660). No E_pass is built, so the 3 loser
%     positions are EXACTLY 0.
%  7. CODA (4 blocks) -> LM head -> token CE (emit_weight 0, plast_weight 1, token-state
%     dropout 0.15). SPAN DECODER (train only, dashed): `tul.spandec`, 2 layers, weight 1,
%     teacher-forced decode of the NEXT span; it reads the uniform MEAN of the 4 final
%     candidates (transformer.py:8777 `tul_fan` = mean; read at 13484 before the routed
%     write; spandec_reads_cells false), NOT the winner.
%  8. GENERATION: per-token cost is prelude + coda, per-boundary one think; only the eager
%     recompute generator runs this model: the KV-cached one refuses fan_k > 0
%     (morph/inference/tul_generate_cached.py:104).
