% TUL — Thought Unpack Loop (mechanism), the PAID LOOP shipped 2026-09-03.
% Recipe: docs/tul-paid-loop-recipe.md; spec: docs/tul-spec.md; decision:
% .agents/notes/implemented/architecture/2026-09-03-ship-the-paid-loop-cut-the-arms.md.
% Star of the show: tokens and slots are ONE sequence. Prelude, the per-sample
% Poisson-depth core and the coda all run on every position. Nothing is
% gathered, projected or scattered; there is no freeze step and no separate
% decode loop. The slot's own emit label carries no loss (emit_weight 0); the
% boundary token keeps its ordinary label (plast_weight 1) and is where the next
% span's first token is read at generation. Exit is the punct / cap rule — no
% learned exit gate.
% Palette follows morph_overview.tex (Paul Tol).
