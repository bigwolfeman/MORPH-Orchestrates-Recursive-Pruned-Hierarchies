% TUL — Thought Unpack Loop (mechanism), THE SLOT LOOP: think once per span, decode
% cheaply. Only the slot positions loop (`_tul_core`); the tokens pass the prelude and the
% coda once and never enter the loop. Spec: docs/tul-spec.md; design:
% .agents/notes/proposed/architecture/2026-09-03-tul-loop-contribution-drawing-board.md;
% the correction that the paid loop (tokens_through_core true) is NOT TUL: memory
% `tul-means-the-slot-loop` (Wolfe, 2026-09-09).
% Star of the show, drawn inside THINK: how the slot's prelude state e becomes the
% thought z. h_0 = e; every pass re-injects e on the context channel
% (h_ctx <- 0.447 h_ctx + e_ctx, morph/model/transformer.py DiagonalInjection) and runs
% the six shared core blocks; after T passes z = h_T is written through W_prefix into the
% slot's two cells. The noise-entry variant (Parcae: h_0 ~ N(0, 0.02^2), e injected on all
% dims through a learned B) is named in the caption. The MUX (the slot's own loss, M-next)
% is the arm under test and is drawn dashed.
% Generation: a new token costs its prelude state and one coda pass (no core pass); a
% boundary costs one think (x T) for the new slot. Exit is the punct / cap rule.
% Palette follows morph_overview.tex (Paul Tol).
% Compile: pdflatex tul_mechanism.tex
%          pdftoppm -png -r 220 -singlefile tul_mechanism.pdf ../tul_mechanism
% Supersedes: the 2026-09-03..09 paid-loop version of this file (git history) and
% tul_overview.tex (deprecated).
