## Problem

The 2026-08 slot-path campaign decomposed TUL's failure into three independent parts,
each with its own filed experiment:

1. **Write.** The main CE (through the coda) writes NOTHING into the plan latent z.
   Specificity 2x2 (aux ON/OFF x TG restriction ON/OFF): 65.1% / 0.4% / 3.0% / 0.3%.
   Only the aux losses (`plast`/`emit` half-weights, spec §5) put span-specific content
   into z, and `emit` is a one-token race the free token path wins.
   (`lab/experiments/planned/2026-08-28-plan-span-specificity.md`)
2. **Dynamics.** Every arm with a core loop took over — 4 of 4 at the pinned
   t_beta3=3500 horizon — and the takeover ERASES plan content (65.1% -> ~1% within a
   few hundred steps). Mechanism: BPTT through the iterated core map with block backward
   gain > 1 (expansive, rho(J_core) > 1). A3 (`n_core: 0`) cannot detonate and beat the
   best TUL arm by 0.84 nats val token-CE at step 4250 at 2.38x the training speed.
   (`lab/experiments/planned/2026-08-28-does-the-slot-apparatus-pay.md`)
3. **Read.** The coda is a competent reader that reads z only under token scarcity:
   plan worth 0.0148 nats with tokens present, 0.0867 nats at token_state_dropout p=1.0,
   where 100.5% of the worth is span-specific (ctrl-s3, the positive control).
   (`lab/experiments/planned/2026-08-28-reader-or-target.md`)

So: the pen exists but is one token wide, the machine holding it detonates, and the
reader has no reason to read at seq_len 1024. Reader-side fixes are falsified; the only
levers left are the WRITE objective and the LOOP's training rule.

## Proposal

Rebuild the slot path (THINK stage only; spans/slots/coda skeleton unchanged) as a
flow/denoising process, per DiffusionBlocks v4 (arXiv 2506.14202) §2.2/§5.5:

- **The core loop becomes a denoiser.** Slot state z_sigma = y_{i+1} + sigma*eps; each
  loop iteration is one Euler step down the sigma ladder, conditioned (attention) on the
  span-i context. Inference iterates; training NEVER does: each training step samples one
  sigma from the iteration's band and takes a single-pass denoising loss. No BPTT through
  the loop. The Euler update is a contraction by construction (alpha = 1 - dsigma/sigma < 1),
  so the takeover disease (finding 2) is structurally removed, not clamped.
- **The target is the NEXT span, never the current one.** y_{i+1} = pooled prelude
  representation of span i+1 (co-trained), regularized with SIGReg (LeJEPA/LeVJEPA,
  lambda=0.02, M~1024 sketch directions) so the target space cannot collapse without any
  EMA teacher or stop-gradient. Fallback target: bag-mean of span-(i+1) token embeddings
  — then the table MUST be detached (lm head is weight-tied) and L2-normalized (DB App. C).
- **Sigma recipe lifted, not re-derived:** log-normal P_mean=-1.2, P_std=1.2,
  equi-probability partitioning of [sigma_min, sigma_max] over loop iterations, EDM
  weighting with sigma_data=0.5 (our own DB oracle sweep independently found 0.5), overlap
  gamma=0.1. Guards against the SliceScaler failure (77% of training in the autoencoding
  regime).
- **Read pressure at train time:** ramp/sample `token_state_dropout`, and/or train arm CW
  (`coda_token_cut`, docs/tul-compaction-window-spec.md) — keep the last ~2 spans of
  tokens, history only as z prefixes. Wolfe proposed exactly this shape on 2026-08-28;
  CW's eval screen (2026-08-18) already showed the slot carries a small unforced signal.
- **Poisson depth becomes ODE step count** — anytime compute with defined semantics.
- **Two objectives, one gate (Wolfe, 2026-08-28):** the EDM/DiffusionBlocks denoiser AND
  a true conditional flow-matching arm (straight-line interpolation, velocity target)
  both run under the SAME retrieval probe; no objective-level conclusion from one alone.
  Model-level comparisons vs the non-TUL baseline use held-out token CE + AR generation
  with the diversity guard — never MAUVE (docs/tul-fm-probing.md §6-7).

Staged build (each stage gates the next, see docs/tul-fm-probing.md for the gates):
1. **P1 — planner alone on a FROZEN checkpoint** (A3-s2 step_4500 or ctrlworth-s3
   step_3000): train only the FM slot path with its local loss. Cheap, cannot take over,
   answers "can this objective write span-(i+1) content into z at all?"
2. **P2 — wire the coda**: joint fine-tune under token scarcity; does the coda read it?
3. **P3 — from-scratch run** only if P1 and P2 gate through.

## Why this does not reopen the DB rejection

The 2026-08-21 rejection measured DB as a replacement for next-token prediction on the
TOKEN path, in a clean-room testbed, and it lost cleanly (AR 4.0010 vs best DB 5.0801 CE).
That verdict stands. TUL-FM applies the same machinery to the PLAN LATENT — a target that
today has NO working write objective (finding 1) — while the token path keeps ordinary CE.
Nothing in the rejection note tested that. If P1 fails, this note moves to rejected/ and
the DB line is fully closed on MORPH.

## Alternatives considered

- **Ship A3 and delete the slot apparatus.** The current default winner and the null
  hypothesis TUL-FM must beat. Costs nothing, gives up the planning thesis. TUL-FM P1/P2
  are cheap enough (frozen backbone, no takeover risk) to run before conceding.
- **Keep aux losses, cure the takeover directly** (spectral penalty, gain clamps,
  ademamix alpha caps). Tried across the campaign; every lever so far is a lever, not a
  cure, and the aux content is destroyed at onset. The disease is the training rule.
- **MUX local head** (2026-08-25 pivot): span-level content gradient through the model's
  own readout. Built and run; did not prevent takeover and did not make the plan load-bearing.
- **Reader-side fixes** (injection, per-layer projections, raise dropout at eval):
  falsified by the reader-or-target sweep — there is nothing to read in aux-off arms, and
  the reader is already competent when forced.
- **Long-context first (4096+), architecture unchanged:** deferred, not rejected — it is
  the setting where any plan finally has work to do; P3 should run there if P2 gates.

## Acceptance criteria

- P1: retrieval probe (docs/tul-fm-probing.md §3) top-1 >> 1/N chance on held-out rows;
  shuffle-cost dose-response reproduces the ctrl-s3 signature shape; SIGReg keeps target
  effective-rank up (no collapse).
- P2: plan worth (shuffle COST, not fraction) at p=0.9 >= ctrl-s3's 0.0800 nats; block
  backward gain < 1.0 for every probed step; ce_main within the control band.
- P3: beat A3 at matched WALL-CLOCK (not steps) at 1024, or beat A3-at-4096 on
  distance-stratified CE, or win multi-span generation coherence (rep4/distinct-3 with
  the diversity guard) at matched CE.
- Every run pre-registered under `lab/experiments/planned/` before launch, as always.

## Risks

- **The ceiling.** At seq 1024 the best measured plan is worth 0.0867 nats fully starved,
  0.0148 unstarved. If P3 stays at 1024 and chases CE, this arc cannot pay; the payoff
  must come from long context, stability/cost, or generation coherence.
- **Target gaming.** A co-trained pooled target can drift toward triviality even with
  SIGReg (SIGReg guarantees the marginal distribution, not informativeness). The
  retrieval probe is the guard; run it throughout P1, not only at the end.
- **Seed/OOD shock.** Forcing new inputs into a frozen backbone (P1/P2) measures an
  OOD-shocked lower bound (the seed_bagmean B2 falsification is the precedent). P1
  failure is decisive only if the probe ALSO fails on a healthy aux-ON checkpoint.
- **DB's own AR result at OWT scale was parity, not a win** — the honest prior on
  latent-side gains is small until token scarcity or length makes the plan load-bearing.
- n=1 positive control: every "what a working plan looks like" number rests on ctrl-s3.
