# Agent Note: The gist loop — gradient-carrying writes, loop out of the graph, plans that route

Status: proposed

## Problem

Four mechanisms (dropout tax, CW deletion, TG rerouting, FM2 direct read supervision
— last one still scoring) have not produced a coda that reads slot content, while the
writer is provably accurate (FM planner retrieval top-1 ~0.70) and the interface
provably delivers nothing (oracle probe: true target at the prefix = 0.0000 nats).
Wolfe's research digest (2026-08-29, pasted in-session; treat its numbers as leads,
not facts — the model that produced it hallucinates) and our own record converge on
the same causal pincer:

- **Gradient through the write is necessary.** TG paper Table 1 (verified, we read
  the paper): detaching the memory write costs 10x PPL. Gisting (Mu et al. 2023,
  real, well-replicated): context CAN be packed into a few positions and decoded —
  when the LM loss backpropagates through the compression bottleneck end-to-end
  under an attention mask that makes the gist the only route.
- **Gradient through the ITERATED write is fatal.** BPTT through the loop is the
  takeover mechanism (2026-06-19 iterative-map note; the whole 08-campaign).
- **Myopic first-token supervision is the collapse trap.** The digest's sharpest
  transferable claim, matching our own `first_tok_counterfactual` history: a
  latent supervised only by a target the token prefix already predicts is solved
  by the shortcut; span-level targets (BoW summary / future-summary vectors)
  cannot be. (Digest sources SIM-CoT/LOTUS/FSP/MUX — arXiv IDs NOT verified by
  us; the mechanism claim is independently supported by our measurements.)

Wolfe's direction (2026-08-29): the gist loop, plus the plan-as-router job
(design #3 of the 2026-08-28 reassessment — the only job TUL ever measurably won
at: conditional compute, 1.6x wall clock).

## Proposal

Staged — one falsifiable claim per stage.

**GL1 — the gist baseline (no loop anywhere).** Prove the write/read pair works
before adding anything:
- Write: slot state = hidden-state TAP at the span's boundary token (TG's recipe;
  our bag-mean was measured losing signal on a −0.5 power law with span length —
  the named source of TUL's deficit vs TG's own numbers). Full gradient, one step,
  no detach, no planner.
- Read: gisting mask — tokens attend their own span (+ optionally the previous
  span) plus ALL earlier slots; slots are the only route to older context. This is
  TG's restriction, which we already have built (`tg_restrict`), minus the two
  things that poisoned the TG arms: the core loop in the gradient path (takeover)
  and the bag-mean write (dilution). That cell of the design space — mask +
  gradient-carrying tap + NO loop — is unexplored.
- Loss: token CE only. No aux heads. The mask makes the slot load-bearing by
  construction; the gradient through the write lets it learn to be.
- Gate: `worth_shuffle` and `first_tok_counterfactual` — same instruments, now
  with a mechanism that gisting proves can work. Honest reference: TG restriction
  cost 0.17–0.42 nats vs unrestricted at matched steps; GL1's claim is that the
  tap write (not the restriction) closes that gap. If GL1 still loses ≥0.15 nats
  to the unrestricted control at matched steps with slots load-bearing, the
  architecture pays for reliance with quality and the trade must be priced, not
  assumed away.

**GL2 — the loop, outside the graph.** Add the refiner: the (already built,
stably training) FM planner machinery iterates on GL1's slot states, DETACHED;
its refined state trains the one-step write head by self-distillation (write
matches refined, lookahead style) and/or serves inference. The loop improves the
state; the gradient never unrolls it. Falsifiable claim: refined slots beat
one-step slots on val CE at fixed params.

**GL3 — the router (the "#3" job).** The slot state gates per-span compute:
refiner depth at inference and ReMoE expert routing in the span's tokens (the
TileRouter machinery exists). The plan stops competing with the previous token on
content and decides where compute goes — the information the token stream does
not carry. Metric: CE-per-FLOP, the metric the original TUL result already won.
Sequenced last because routing on non-load-bearing slots is noise (GL1 must pass
first).

**Bridge arm (cheap, current architecture, contingent on FM2 nulling):**
FM2b — replace the myopic emit target with a span-level auxiliary decoder on the
slot state (predict the next span's bag-of-words through a small discardable
head). The digest's SIM-CoT/FSP prescription inside the existing model; one
config + one small head, no architecture change. Runs only if we want one more
datum before committing to GL1's build.

## Alternatives considered

- **Per-layer cross-attention injection** (digest calls it optimal, citing TG):
  contested by Block Transformer Fig 3f (−0.18 nats vs prefix at BPE scale,
  verified in our references). Our prefix positions already are layer-visible
  attendable KV; deferred unless GL1 shows the mask alone is insufficient.
- **Best-of-K explorative writes (digest doc-2 Intervention 3):** addresses
  mode-averaging, a failure we have not yet demonstrated is binding (our writer
  is accurate; our reader is absent). Revisit at GL2 if refinement targets prove
  multi-modal. Source paper unverified.
- **Distill the CW gap (teacher-student, CODI shape):** still attractive, more
  moving parts than GL1, kept as the fallback if the gisting mask underperforms.
- **Free-bits / VAE machinery:** our latent is deterministic and accurate; the
  failure is the reader, not information content of z. Not applicable now.
- **Trained-oracle ceiling run:** superseded as the next step by Wolfe's
  direction, but remains the cheapest way to bound GL1's prize if we want it
  (train a CW coda with oracle y from step 0).

## Acceptance criteria

Each stage gets its own pre-registration in `lab/experiments/planned/` before any
run. GL1's headline gates: `worth_shuffle` ≥ 0.05 sustained AND
`first_tok_counterfactual` > 0, at ≤0.15 nats cost vs the unrestricted control at
matched steps. This note is superseded per-stage as results land.

## Risks

- TG's measured restriction cost may be intrinsic, not write-quality — GL1's
  central bet. Priced by the matched-steps control arm.
- The tap write reintroduces a gradient path from future-span CE into shared
  weights at the boundary token; no iterated map exists, but the emit-fuel
  history says watch the grad-share probes from step 0.
- `tg_restrict` currently forces eager (no fused kernels) — GL1 inherits the
  ~2.3x slowdown; acceptable for 4500-step arms, priced before any long run.
